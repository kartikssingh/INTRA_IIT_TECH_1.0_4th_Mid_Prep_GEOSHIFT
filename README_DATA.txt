# GeoShift — Satellite Intelligence Across Unseen Regions

Six-class multispectral satellite land-cover classification.

Channels:
0 = B02 Blue
1 = B03 Green
2 = B04 Red
3 = B08 Near Infrared

Tile:
64 × 64 pixels at 10 m resolution.

Classes:
0 Forest
1 Shrubland
2 Grassland
3 Cropland
4 Built-up
5 Water/Wetland

Metric:
Macro F1.

The participant data are constructed from geographically disjoint regions.
Class balancing has NOT been applied; the natural regional distribution is
preserved.

The hidden answer key is maintained by the competition organizer.
